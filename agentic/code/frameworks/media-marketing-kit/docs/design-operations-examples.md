# Design Operations Examples

These examples use the same lifecycle—constraints, history, research, five comparable candidates, human selection, persistence, adaptation, and QA—at different scales.

## Monthly project update hero

Use `choose-theme` with the last six monthly themes as rotation evidence. Keep the same headline, summary, CTA, 1440x720 comparison canvas, and sample fidelity across five directions. Record dated trend citations, identify overused motifs, and save the approved result as `monthly-update-2026-08` with future rotation guidance. Run `web-hero` for responsive reflow, text/focal safe areas, AVIF/WebP exports, and WCAG checks.

## Landing-page hero

Run `theme-from-brand`, then `web-hero`. Treat logo, core palette, type family, and product UI fidelity as invariants while varying metaphor, composition, imagery, texture, and motion. Produce desktop/tablet/mobile layouts and specify maximum responsive-image weights before handing off to `landing-page-visual-system`.

## Social asset family

Run `social-asset-family` from an approved theme. Preserve palette roles, typography character, graphic grammar, and imagery treatment while adapting hierarchy to 1200x628, 1080x1080, and 1080x1920. Record platform UI safe zones, RGB exports, mobile legibility, motion/reduced-motion variants, and filename conventions in the adaptation matrix.

## Presentation theme

Run `presentation-theme` from the same selected theme. Define 16:9 title, section, content, quote, image, and chart masters; accessible reading order; minimum type sizes; chart color differentiation beyond hue; image cropping; and PPTX/PDF delivery. Link the presentation template to the theme ID so its use becomes part of rotation history.
