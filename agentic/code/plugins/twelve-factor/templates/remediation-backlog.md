## Task Shape

Each remediation task should include:

- The factor and finding it resolves
- Current evidence and missing evidence
- Concrete implementation or documentation work
- Verification command, test, review artifact, or runtime signal
- Links to requirements, ADRs, code/config, tests, issues, or PRs
