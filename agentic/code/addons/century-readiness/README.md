# Century-Scale Readiness Review

This addon asks what future maintainers need to preserve obligations, replace
dependencies, rehearse migrations, degrade safely, audit decisions, and retain
meaning—not whether a system can literally be guaranteed for a century.

```bash
aiwg use century-readiness
aiwg century-readiness review agentic/code/addons/century-readiness/fixtures/aiwg-self-review.json
```

The public-core slice is a local checklist, fixture, deterministic report, and
migration-rehearsal candidate list. Organization governance, board reporting,
managed dependency inventory, and audit services are enterprise candidates and
are not implemented here.

Agentic Sandbox release evidence may be reviewed when locally available. A
missing external evidence package must be reported as `NOT RUN` with its
dependency reason rather than inferred as passing.
