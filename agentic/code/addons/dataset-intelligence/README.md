# Dataset Intelligence

Dataset Intelligence is AIWG's core, auto-installed interaction layer for
turning a source and desired outcome into a governed dataset plan. It is usable
from SDLC, research, knowledge-base, media, marketing, operations, and
project-local work without requiring users to know indexing or provenance
terminology.

The addon is declarative. Agents, skills, and flows advise, review, and delegate
to the shared `aiwg dataset` orchestration service. They never implement a
second ingestion runtime. Canonical source data remains canonical; indexes,
graphs, embeddings, and Fortemi shards are derived or regenerable artifacts.

See [the overview](docs/overview.md), [quickstart](docs/quickstart.md), [task
guide](docs/task-guide.md), [worked examples](docs/worked-examples.md), and
[migration guide](docs/migration-guide.md).
