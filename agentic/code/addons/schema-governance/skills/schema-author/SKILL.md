# Schema Author

Read the schema brief. Select the real authority language, assign a stable
logical name and `https://aiwg.io/schemas/` identity, create the canonical
contract and valid/invalid fixtures, declare consumers/dependencies/policy and
projections, then regenerate the catalog. Run `aiwg schema lint`, `check-refs`,
fixture validation, projection verification, and typecheck where applicable.
Do not substitute prose examples for an executable contract.
