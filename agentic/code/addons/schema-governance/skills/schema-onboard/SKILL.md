# Schema Onboard

Explain schemas as shared, executable agreements that prevent silent data drift.
Start from the user's real examples and desired failures. Avoid asking them to
choose dialects, identifiers, or compatibility modes; the Schema Steward derives
those choices and exposes only consequential trade-offs. Continue into
`schema-intake` rather than ending with education alone.
