# Network analysis addon changelog

## 2026.9.0 - 2026-09-05

- Added provider-neutral v1 schemas for governed recipes, packet evidence, and
  authorization/disclosure records.
- Added fail-closed TShark/Capinfos probing, bounded offline PCAP/PCAPNG
  analysis, metadata-first evidence, stable citations, and deterministic
  JSON/JSONL/Markdown output.
- Added nine versioned recipes for overview, endpoints/conversations, DNS, TCP,
  TLS, HTTP metadata, streams, timing, and before/after comparison.
- Added an explicit local Termshark 2.x handoff, research induction, additive
  forensic custody mapping, security review contexts, and SDLC/Ops comparison.
- Added deterministic MIT-licensed fixtures, a machine-readable conformance
  report, supported-provider deployment tests, and npm package smoke coverage.

Live capture, privilege changes, active scanning, capture transfer, and provider
payload upload remain outside the released default workflow.
