   existing projects and reconciled Windsurf guidance.

   announcement language and added a dated correction to the 2026.6.13 note.
7. **Workflow route-variable names** — corrected the npm and GitHub mirror
   route names in the workflow README.

   lockstep manifests, changelog, announcement, and release manifest.
