## Findings

- Fortemi Core prebuilt framework index behavior needed a package-facing doc
  contract. Added `docs/fortemi-core-prebuilt-indices.md` coverage for the
  generated files, compact metadata/capability projection, `prepack`,
  `ci:fortemi-index`, tarball validation, and packaged fallback behavior.
- Storage docs still described the older `fortemi` MCP adapter as a current
  Fortemi path without clearly separating it from the new search/index backend.
  Updated storage overview, backend, migration, security, and CLI text to mark
  that adapter as persistence-only and deprecated for discovery/search routing.
- Release-facing docs did not yet mention that npm packages include the prebuilt
  framework index. Updated the Fortemi export guide, 2026.7.1 announcement, and
  changelog so the distro package behavior is visible to release reviewers.
- Package-size documentation needed to reflect that the prebuilt framework index
  is now an intentional distro artifact rather than per-user generated state.
  Updated the install-size budget rationale while keeping a separate
  Fortemi-specific prebuilt export ceiling.
