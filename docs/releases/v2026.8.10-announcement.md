# AIWG 2026.8.10 - Deterministic release packaging

**Release date:** 2026-08-15
**Channel:** stable

AIWG 2026.8.10 is the immutable-tag recovery release for 2026.8.9. It contains
the same provider deployment, split-root workflow, documentation, and setup
improvements, plus a correction for clean-checkout npm publication tests.

## What changed

- Clean release checkouts now generate the ignored Fortemi Core package index
  before building the lifecycle-script-free global-install test tarball.
- Packaging holds the shared prebuilt-directory lock while reading the
  generated index, preserving deterministic discovery and doctor checks when
  package tests run concurrently.
- Self-verifying provider deployment tests allow a bounded three-minute
  subprocess budget, avoiding false failures on loaded hosted runners.
- OpenClaw's cross-agent compatibility mirror honors the requested project
  target, so isolated deployments cannot mutate the AIWG source checkout.
- The intended default provider copy profile remains the 25 kernel and
  quick-reference skills. Full standards deployment remains explicit.

## Upgrade

Install all AIWG packages at version `2026.8.10`. After upgrading, ask your
coding agent to deploy AIWG for the provider you use and verify that the project
is engaged.

## Rollback

Roll all three npm packages back together to `2026.8.8`, then redeploy the
project's provider assets and regenerate its context files. Version 2026.8.9
was tagged but its npm publication did not complete.
