# AIWG 2026.7.15 - "Windows portability fixes"

**Released:** 2026-07-20  
**Channel:** stable (`npm install -g aiwg`)

AIWG 2026.7.15 fixes two Windows path-handling defects reported against native
Claude Code and the shared artifact graph index. The changes are narrow and
backward compatible; no provider sessions or migrations are required.

## Highlights

- **Shell-safe Claude Code hooks**
  ([#133](https://github.com/jmagly/aiwg/issues/133)) — generated hook commands
  now use forward-slash script paths on every platform. Redeploying also
  repairs existing AIWG-managed hook commands containing Windows backslashes,
  preventing Claude Code from collapsing them into invalid module paths.
- **Cross-platform shared index home**
  ([#132](https://github.com/jmagly/aiwg/issues/132)) — when
  `XDG_DATA_HOME` is absent, AIWG now resolves the user's home directory with
  Node's platform API instead of interpolating an unset `HOME` variable. This
  prevents creation of a literal `undefined/.local/share` directory in Windows
  projects.

## Upgrade

```bash
npm install -g aiwg@latest
cd your-project
aiwg use all
```

Running `aiwg use all` refreshes existing AIWG-managed Claude Code hooks with
the corrected command paths. Projects that only use artifact indexing receive
the corrected shared-index location automatically. No breaking changes.
