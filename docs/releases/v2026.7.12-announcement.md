# AIWG 2026.7.12 - "Cockpit recovery and LFD controls"

**Prepared:** 2026-07-11  
**Channel:** stable (`npm install -g aiwg`)  
**Status:** release artifacts prepared; tag and publish are intentionally not cut yet.

This patch prepares the next stable release after `v2026.7.11`. It packages the
Cockpit stale-agent recovery work and the repaired LFD control surface for
external agent loops while UAT continues.

## Highlights

- Adds Cockpit **Reconnect** for stale Docker/container agents. Inventory and
  Sessions keep the runtime visible, label it `agent unreachable`, and route the
  recovery request through the Bridge.
- Exposes Bridge recovery as `POST /api/instances/:id/reconnect`, preferring
  executor-owned reconnect endpoints and falling back to the sandbox
  `agent-reconnect` helper in current container images.
- Documents the full Cockpit operator workflow: launch with the host daemon,
  read transport and host-daemon posture, recover stale agents, and attach to
  sessions without losing the running instance.
- Ships the LFD remediation batch for external Ralph/agent-loop controls:
  resumed budgets, unknown-vs-zero usage semantics, completion-vs-budget stop
  policy, declared exploration quota, stall rule, hypothesis records,
  holdout-isolated mode, eval harness, VOID runtime, and CI coverage.
- Adds the bounded manual provider test runbook for validating LFD controls
  against real CLIs after the deterministic UAT lane passes.

## Upgrade

```bash
npm install -g aiwg@latest
aiwg --version
aiwg use cockpit
aiwg cockpit
```

For a real local Cockpit stack with host-runtime coverage:

```bash
AIWG_COCKPIT_START_HOST_DAEMON=1 npm run cockpit:up
```
