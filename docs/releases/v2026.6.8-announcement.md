# AIWG 2026.6.8 — "@aiwg/cockpit npm README polish"

**Released:** 2026-06-21
**Channel:** stable (`npm install -g aiwg`)

Maintenance cut to refresh the `@aiwg/cockpit` npm package page now that the
trusted-publishing path is validated.

---

## What changed

The Cockpit README now starts like the main AIWG README: product framing first,
then install commands, badges, quick links, and short operator-facing sections
before the deeper architecture and validation runbook.

The recommended install path is explicit:

```bash
npm i -g aiwg
aiwg use cockpit
aiwg cockpit
```

That path installs `@aiwg/cockpit` outside the base package footprint under
`~/.aiwg/cockpit/package` and keeps it version-locked to the base `aiwg` CLI.
Direct package installation remains documented for package testing:

```bash
npm i -g @aiwg/cockpit
aiwg-cockpit
```

---

## Upgrade

```bash
npm install -g aiwg     # 2026.6.8
aiwg version            # -> 2026.6.8 [stable]
```

**No action required.** Documentation/package-page release; no CLI behavior
changes.
