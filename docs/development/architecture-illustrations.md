# Architecture illustration production

The public architecture overview uses Mermaid diagrams as the canonical visual
source. Polished raster illustrations are optional presentation assets for the
website or release posts; they are not required for the Markdown document to be
complete.

Maintainers can generate images for these eight diagram slots:

1. `01-deploy-tool.png`
2. `02-two-tier.png`
3. `03-discover-show.png`
4. `04-optional.png`
5. `05-aiwg-dir.png`
6. `06-hermes-resolver.png`
7. `07-multi-target.png`
8. `08-reload.png`

Store finished assets under `docs/architecture-overview/images/` only after the
files exist and render correctly in the documentation build. Keep prompt drafts,
style variants, and production notes in maintainer issues or this development
note rather than the public overview.
